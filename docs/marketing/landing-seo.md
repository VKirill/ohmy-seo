# Лендинг и поисковая структура ohmy-seo

Реализовано 14 сентября 2026 в `hosting/apps/web`. Сайт ещё не развёрнут этой задачей на production.

Это карта намерений для первоначальной структуры, не семантическое ядро с измеренной частотностью. Частотности и прогнозы трафика не придумывались. Опечатки вроде «диретк» не размножаются по заголовкам. Страницы отличаются содержанием, задачами, инструментами и условиями доступа.

## Содержимое

- Главная: оффер, три переключаемые учебные демонстрации, рабочие сценарии, все 10 интеграций, копируемые запросы, процесс подключения, ограничения, варианты установки, FAQ.
- Интеграция: назначение, возможности, запрос, ожидаемый результат, примеры реальных инструментов, требования и ограничения, ссылки на README и смежные сервисы.
- Инструкция: облачный Claude Code с HTTP/Bearer, требования других клиентов, локальная сборка, stdio-пример Roistat, ошибки.
- `/connect`: выбор OAuth-провайдера. Страница не индексируется. Кнопки начала работы ведут сюда: существующий `/app` возвращает гостя на главную и не служит самостоятельным экраном входа.

## Техническое SEO

Статическая генерация публичных страниц, отдельные title/description/H1, canonical на `https://ohmy-seo.ru`, Open Graph с PNG 1200×630, SoftwareApplication на главной, BreadcrumbList на интеграциях, sitemap из единого каталога. robots.txt закрывает обход `/app` и `/api/`; это не механизм контроля доступа. В sitemap только 12 содержательных страниц, без кабинета и выбора входа.

Нет фиктивных рейтингов, отзывов, цен и обещаний позиций. По уточнению владельца 14.09.2026, ohmy-seo — бесплатный инструмент специально для маркетологов: облачный доступ и локальные пакеты. AI-клиенты и сторонние сервисы могут оплачиваться отдельно. Это отражено на первом экране, в блоке доступа, FAQ, метаданных и SoftwareApplication/Offer. Учебные демонстрации содержат явно помеченные вымышленные данные.

## Источники возможностей

`README.md`, README отдельных пакетов, `hosting/OPERATIONS.md`, состав пакетов в `hosting/apps/gateway/src/runtime.ts`, OAuth-права в `hosting/apps/web/src/lib/providers.ts`.

Облако включает пакет Яндекса и чтение GSC/GA4/GTM. Google Ads и Roistat — отдельные пакеты. Mutagen/XMLStock в облаке зависят от ENABLE_SHARED_SERP. Подключение нового приложения Директа зависит от одобрения. Яндекс Аудитории и Облако не перечислены как готовые интеграции: наличие OAuth scope не равнозначно наличию MCP-инструментов.

Синтаксис подключения Claude Code сверялся с [официальной документацией Anthropic](https://code.claude.com/docs/en/mcp). Работа авторизованных внешних API в этой задаче повторно не тестировалась.

- Глобальные маркетинговые стили ограничены `.marketing` и `body:has(.marketing)`; страница приватности использует ту же маркетинговую оболочку и светлый стиль; содержание политики сохранено.

Добавлена `/prompts`: 40 шаблонов по 10 сервисам, вкладки с клавиатурной навигацией,
копирование, подсказки для подстановки аккаунтов и периодов, ссылки на интеграции.

ссылки также добавлены в навигацию и подвал. Страница включена в sitemap,
получила отдельные title, description, canonical и Open Graph.

`/connect` теперь описывает вход только через Яндекс и отдельное подключение
рабочих аккаунтов в кабинете. Инструкция, главная и текст приватности согласованы
с этим разделением. Детали приложений и переноса прежних кабинетов — в
`hosting/OPERATIONS.md`.

Проверено: Next build, TypeScript, 27 hosting-тестов с изолированным PostgreSQL,
метаданные и ссылки 13 публичных страниц, мобильная ширина 390 px.

### Расширение библиотеки и исправление переключения

Библиотека содержит 88 вопросов. В Директе, Метрике, Вебмастере, GTM,
Mutagen и XMLStock — по 12, в остальных четырёх сервисах — по 4.
Вкладки заменены нативными ссылками `?service=<slug>#questions`: выбранный сервис
отрисовывается сервером, сохраняется при обновлении страницы и открывается
без клиентского JavaScript. Это заменяет прежнее переключение через React state.
Canonical всех вариантов остаётся `/prompts`; метаданные берут актуальное число
вопросов из данных. Некорректный параметр открывает Директ.

Проверено: сборка Next.js, TypeScript, HTTP-переходы по всем 10 сервисам без
JavaScript, неизвестное/пустое значение service, реальный клик на Метрику в браузере,
12 карточек и мобильный вид 390 px без переполнения. Публичное превью защищено
авторизацией BB; браузерная проверка выполнялась на локальном адресе того же сервера.
