# Google Ads Workspace Gotchas

**TL;DR:** Account selection, GAQL preflight, and mutation confirmation rules can make a valid-looking tool call return an error or a preview instead of the expected API result.

## Critical

### A mutation call can succeed as a preview without contacting Google

**Problem:** Omitting `confirm:true` returns a dry-run payload and does not call the Google Ads API (`packages/google-ads/src/lib/ads-mutate.ts:69-76`).

**Risk:** Treating preview output as an applied change leads to incorrect assumptions about account state.

**Workaround:** Follow the operation-specific safety requirements on [campaign management](features/campaign-management.md); verify the returned `applied` or `validated_only` values (`packages/google-ads/src/lib/ads-mutate.ts:119-127`).

### Live writes are blocked by a global environment switch

**Problem:** A confirmed live mutation returns an error unless `GOOGLE_ADS_ALLOW_LIVE_MUTATIONS` equals `true`; validation-only calls bypass this check (`packages/google-ads/src/lib/ads-mutate.ts:78-88`).

**Risk:** An otherwise valid request does not change Google Ads state.

**Workaround:** Check the environment on the server process running the package and restart after configuration; the executor's error response names the setting (`packages/google-ads/src/lib/ads-mutate.ts:78-85`).

## High

### Omitting the account does not select the sole account automatically

**Problem:** The resolver only uses the default account when no label is passed; if none is marked default, it raises `AmbiguousAccountError` (`packages/google-ads/src/lib/account-resolver.ts:37-47`).

**Risk:** Read or write tools fail despite a connected account existing.

**Workaround:** Pass the account label or set a default with `set_default_google_account` (`packages/google-ads/src/lib/account-resolver.ts:13-19`, `packages/google-ads/src/lib/db/accounts-repo.ts:230-241`).

### Raw GAQL does not accept multiple statements or OFFSET

**Problem:** The raw query validator rejects semicolons, non-SELECT input, missing FROM, OFFSET, and missing required primary fields (`packages/google-ads/src/lib/gaql-builder.ts:107-128`).

**Risk:** A query copied from another SQL dialect or resource example fails before it reaches Google.

**Workaround:** Use one GAQL SELECT query, check resource fields with `ads_resource_metadata`, and provide filters or LIMIT instead of OFFSET (`packages/google-ads/src/index.ts:330-338`, `packages/google-ads/src/lib/gaql-builder.ts:107-151`).

## Medium

### OAuth callback waits only five minutes

**Problem:** The loopback OAuth callback wait is 300,000 milliseconds; timeout returns an error and asks for a new flow (`packages/google-ads/src/tools/start-google-oauth-flow.ts:45-55`).

**Risk:** Completing browser authorization after the listener times out does not create an account record.

**Workaround:** Open the printed authorization URL promptly and rerun `start_google_oauth_flow` after timeout (`packages/google-ads/src/tools/start-google-oauth-flow.ts:45-53`).

### Registered OAuth redirect URI is not used by the start flow

**Problem:** App registration persists `redirect_uri`, but the OAuth flow constructs and exchanges the authorization using the callback URL generated by its loopback listener (`packages/google-ads/src/lib/db/oauth-apps-repo.ts:57-84`, `packages/google-ads/src/tools/start-google-oauth-flow.ts:34-43`, `packages/google-ads/src/tools/start-google-oauth-flow.ts:58-63`).

**Risk:** The stored URI can differ from the URI Google receives during authorization, causing the callback exchange to fail if the generated callback URI is not registered with the OAuth client.

**Workaround:** Register the loopback callback URI generated by this flow in the Google OAuth client; the configured listener port is controlled by `MCP_GOOGLE_ADS_OAUTH_LOOPBACK_PORT` (`packages/google-ads/src/tools/start-google-oauth-flow.ts:30-35`).

## Low

### Google Ads customer IDs are normalized to digits

**Problem:** Hyphens and other non-digit characters are removed before calls (`packages/google-ads/src/lib/ads-client.ts:46-48`, `packages/google-ads/src/lib/ads-client.ts:363-377`).

**Risk:** A malformed ID containing letters can be transformed into a different digit string instead of rejected as formatted input.

**Workaround:** Supply the intended numeric customer ID, optionally with grouping dashes only (`packages/google-ads/src/index.ts:137-138`).
