# Google Search Console MCP API

TL;DR: Clients call MCP tools over the package's stdio server; Google-facing HTTP methods and paths below are generated by the individual tools (`packages/google-search-console/src/index.ts:41-59`, `packages/google-search-console/src/lib/gsc-client.ts:74-99`).

## Calling and authorization

The package exposes MCP tool names, not an HTTP route server. The MCP client calls a registered tool; GSC operations then resolve the requested account or default, verify its granted OAuth scope, obtain an access token, and call Google's endpoint (`packages/google-search-console/src/index.ts:70-77`, `packages/google-search-console/src/lib/account-resolver.ts:40-66`, `packages/google-search-console/src/lib/gsc-client.ts:41-90`). `account` is optional on data tools; if omitted, the package selects the account marked default (`packages/google-search-console/src/lib/account-resolver.ts:45-57`).

| Scope constant | Google scope family | Applies to | Evidence |
|---|---|---|---|
| `SCOPE_GSC_READONLY` | Search Console read-only | Property listing, analytics, inspection, sitemap listing | `packages/google-search-console/src/tools/gsc-list-sites.ts:1`, `packages/google-search-console/src/tools/gsc-search-analytics.ts:1`, `packages/google-search-console/src/tools/gsc-url-inspection.ts:1`, `packages/google-search-console/src/tools/gsc-list-sitemaps.ts:1` |
| `SCOPE_GSC_FULL` | Search Console full access | Sitemap submission and deletion | `packages/google-search-console/src/tools/gsc-submit-sitemap.ts:1`, `packages/google-search-console/src/tools/gsc-delete-sitemap.ts:1` |
| `SCOPE_INDEXING` | Indexing API | Indexing notifications | `packages/google-search-console/src/tools/gsc-indexing-publish.ts:1` |

## How it works

1. The MCP client invokes one of the tools registered by `src/index.ts`; the package accepts calls over stdio (`packages/google-search-console/src/index.ts:41-59`, `packages/google-search-console/src/index.ts:444-449`).
2. Account-management calls read or mutate the local repositories. Google API tools resolve the optional account label or default account and check the scope required for that operation (`packages/google-search-console/src/lib/account-resolver.ts:40-66`).
3. For a Google API call, the shared client loads OAuth app credentials when needed, gets an access token, builds the URL, and sends the HTTP request (`packages/google-search-console/src/lib/gsc-client.ts:41-90`).
4. The tool maps the response into its result shape. Cacheable reads use cached data unless their tool supports and receives a force-refresh option; successful non-GET calls invalidate entries for that account (`packages/google-search-console/src/tools/gsc-search-analytics.ts:71-91`, `packages/google-search-console/src/lib/gsc-client.ts:89-99`).

| Mode | Branch and difference | Evidence |
|---|---|---|
| Local account management | Reads/writes OAuth app and account records; no GSC endpoint call. Service-account registration validates credentials with a Google token exchange. | `packages/google-search-console/src/index.ts:118-290`, `packages/google-search-console/src/tools/register-google-service-account.ts:25-52` |
| Search Console read | Read-only scope; property listing, analytics, inspection, and sitemap listing. Four reads use registered cache TTLs. | `packages/google-search-console/src/index.ts:94-111`, `packages/google-search-console/src/index.ts:304-377` |
| Search Console sitemap mutation | Full scope; PUT submits a sitemap and DELETE removes one; successful calls invalidate account cache entries. | `packages/google-search-console/src/tools/gsc-submit-sitemap.ts:31-61`, `packages/google-search-console/src/tools/gsc-delete-sitemap.ts:31-61`, `packages/google-search-console/src/lib/gsc-client.ts:89-99` |
| Indexing notification | Indexing scope; POST accepts `URL_UPDATED` or `URL_DELETED` and returns notification time on success. | `packages/google-search-console/src/tools/gsc-indexing-publish.ts:41-80` |

**Failures:** Unknown explicit account labels and missing scopes throw during account resolution (`packages/google-search-console/src/lib/account-resolver.ts:47-64`). The shared client returns classified authentication/API errors with `ok:false`, propagates rate-limit errors, and throws unclassified errors (`packages/google-search-console/src/lib/gsc-client.ts:100-118`). Sitemap mutation and indexing tools map returned API failures to `success:false`; Search Analytics and URL inspection return the response data directly, including classified error data (`packages/google-search-console/src/tools/gsc-submit-sitemap.ts:49-61`, `packages/google-search-console/src/tools/gsc-indexing-publish.ts:57-69`, `packages/google-search-console/src/tools/gsc-search-analytics.ts:79-91`, `packages/google-search-console/src/tools/gsc-url-inspection.ts:71-80`).

## Account and OAuth tools

These tools call local account/OAuth repositories; their upstream method and path are not applicable. Write/read annotations are the MCP server annotations. The `complete_google_oauth_flow` command is still registered but returns a deprecation error (`packages/google-search-console/src/index.ts:38-39`, `packages/google-search-console/src/index.ts:215-237`, `packages/google-search-console/src/tools/complete-google-oauth-flow.ts:6-19`).

| MCP tool | Method and path | Caller and operation | Auth | Feature |
|---|---|---|---|---|
| `list_google_oauth_apps` | Local read | MCP client; list OAuth app metadata | Local package DB; no Google API call | [Accounts and OAuth](features/accounts-and-oauth.md) |
| `register_google_oauth_app` | Local insert | MCP client; store app and encrypted secret | Local package DB; no Google API call | [Accounts and OAuth](features/accounts-and-oauth.md) |
| `delete_google_oauth_app` | Local delete | MCP client; remove app if no accounts reference it | Local package DB; no Google API call | [Accounts and OAuth](features/accounts-and-oauth.md) |
| `list_google_accounts` | Local read | MCP client; list connected account metadata | Local package DB; no Google API call | [Accounts and OAuth](features/accounts-and-oauth.md) |
| `start_google_oauth_flow` | Browser OAuth authorization-code flow with loopback callback | MCP client; connect a Google user account | OAuth app secret and scopes declared on that app | [Accounts and OAuth](features/accounts-and-oauth.md) |
| `complete_google_oauth_flow` | No request; returns deprecated error | MCP client; directs caller to automatic loopback flow | No Google API call | [Accounts and OAuth](features/accounts-and-oauth.md) |
| `delete_google_account` | Local delete | MCP client; delete account credentials | Local package DB; no Google-side revocation | [Accounts and OAuth](features/accounts-and-oauth.md) |
| `set_default_google_account` | Local update | MCP client; choose default account | Local package DB; no Google API call | [Accounts and OAuth](features/accounts-and-oauth.md) |
| `register_google_service_account` | Google token exchange during validation | MCP client; verify key and save service account | Service-account JSON key and requested scopes | [Accounts and OAuth](features/accounts-and-oauth.md) |

The MCP registrations and write/read annotations are in `packages/google-search-console/src/index.ts:118-290`; the service-account validation performs its token exchange in `packages/google-search-console/src/tools/register-google-service-account.ts:25-39`.

## Errors and cache

The shared client returns classified authentication and Google API failures as `{ok:false,status,data}`; rate-limit errors are thrown for callers to handle. Sitemap writes and indexing translate returned errors into `success:false`, while read tools return response data (`packages/google-search-console/src/lib/gsc-client.ts:100-118`, `packages/google-search-console/src/tools/gsc-submit-sitemap.ts:49-61`, `packages/google-search-console/src/tools/gsc-indexing-publish.ts:57-69`). Search Analytics, inspection, site listing, and sitemap listing use shared cache wrappers; their default TTLs and environment overrides are registered at server startup (`packages/google-search-console/src/index.ts:94-111`).

## Public API

The executable command is `mcp-gsc`, backed by `dist/index.js`; see [workspace overview](overview.md) for startup and configuration (`packages/google-search-console/package.json:6-14`).
